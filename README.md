# Calendrier 1A

A collaborative class calendar app for managing tests, revision tracking, messaging, and class suggestions.

## Features

- 📅 **Shared Calendar**: View all upcoming tests and events
- ✅ **Revision Tracking**: Personal revision status (only visible to you)
- 💬 **Messaging**: Send messages to classmates and create groups
- 💡 **Idea Box**: Submit suggestions, questions, and demands for class improvements
- 🌐 **Bilingual**: Switch between English and French
- 🎨 **Themes**: Choose from dark, light, or colorful themes
- ⚙️ **Admin Settings**: Manage tests, dates, times, and app content

## Installation

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the app: `npm start`
4. Access at http://localhost:3000

## Tech Stack

- Node.js + Express (Backend)
- SQLite (Database)
- HTML/CSS/JavaScript (Frontend)
